# L'Atelier Toki

Site e-commerce fictif pour un atelier de poterie. Projet personnel d'apprentissage full-stack.

## Stack technique

- **Front-end** : React, Vite, Tailwind CSS, React Router
- **Back-end** : Node.js, Express
- **Base de données** : SQLite avec Prisma
- **Outils** : Git, GitHub, VS Code

## Pages prévues

- Accueil
- L'Atelier
- Boutique (3 produits)
- Stages & Cours
- Contact
